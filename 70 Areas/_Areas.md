# 🧭 Areas of Focus

> [!tip]- How to use
> Steady-state responsibilities and life domains that give projects context — **not outcomes themselves**, just things you keep an eye on.
>
> - Create one note per area: Work, Health, Finances, Home, Relationships, Learning, Community, Personal Growth.
> - Link projects to an area via the `area` property so the area page shows its live project + action views.
> - Use during the **weekly review** (and higher horizons: role, goals, purpose) to keep projects aligned with what matters.

## Live area views

Each area note embeds its own filtered views automatically (see [[_bases/Area Actions.base]]).
