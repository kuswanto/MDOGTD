# 🏠 GTD — Command Center

> [!tip]- How to use this system
> Your Getting Things Done system, powered by **Obsidian Bases**. Everything flows in, gets clarified, and lands somewhere it can be trusted.
>
> The flow: [[10 Inbox/_Inbox|📥 Inbox]] → **clarify** → [[20 Next Actions/_Next Actions|⚡ Next Actions]] · [[30 Projects/_Projects|🗂️ Projects]] · [[40 Waiting/_Waiting|⏳ Waiting]] · [[50 Someday Maybe/_Someday Maybe|🌟 Someday Maybe]] · then **do** and **review**.
>
> - Capture anything → [[Templates/Inbox Item|Inbox Item template]]
> - Batch by context (@Computer, @Phone, @Home, @Errands…)
> - Run the **Weekly Review** to keep everything trustworthy
>
> This vault ships with small **Example** notes in each space — keep them as a guide, or delete them and start fresh.
