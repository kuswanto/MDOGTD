# ✅ Completed

Archived **projects** and **actions** that are done. Completion is **manual**: mark `status: done`, set `completed`, then move the note into `100 Completed/Projects/` or `100 Completed/Actions/`.

> [!tip]- How to use
> - Finished a project → set `status: done` + `completed: {{date}}`, move the note to `100 Completed/Projects/`.
> - Finished an action → set `status: done` + `completed: {{date}}`, move the note to `100 Completed/Actions/`.
> - Don't keep doing work inside the completion spaces — they're a graveyard, not a queue.
> - Optionally purge the oldest entries during a monthly or quarterly review.
