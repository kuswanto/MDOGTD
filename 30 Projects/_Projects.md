# 🗂️ Projects

> [!tip]- How to use
> Outcomes that require **more than one action step** to complete. Each project is a note here; its next actions live in [[20 Next Actions/_Next Actions|Next Actions]] and link back via the `project` property.
>
> - Create one note per open project (e.g. "Plan Q3 marketing", "Renovate the shed", "Launch side project").
> - Set properties: `status` (active | waiting | done), an optional [[70 Areas/_Areas|area]], and `project` to link the action list.
> - When a project is done: set `status: done`, set `completed: {{date}}`, and move it to [[100 Completed/_Completed|Completed]] → `Projects`.
> - Add the outcome in one line at the top of each project note, then brainstorm support material below.
> - During processing / weekly review, add the very next physical action for each project into Next Actions and link it via `project`.
