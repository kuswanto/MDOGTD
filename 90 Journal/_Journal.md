# 📆 Journal

> [!tip]- How to use
> Daily notes and the **capture surface** for time-stamped stuff. Anything you note during the day lands here via the daily note; process leftovers into the GTD spaces.
>
> - A daily note is created automatically by the Obsidian Daily Notes plugin (template: `Templates/Daily`).
> - Use it for capture, logs, and as the processing scratchpad for that day.
> - Move clarified items into the GTD spaces; don't let actions rot in journal notes alone.
