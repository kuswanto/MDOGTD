# ⏳ Waiting

> [!tip]- How to use
> Things you're **waiting on someone else** to deliver or respond to before you can proceed.
>
> - One note per outstanding item: who, what, by when.
> - Use the `waiting_on` property to track the person/org, and `due` for the expected date.
> - If a follow-up action is needed on your side, place it in [[20 Next Actions/_Next Actions|Next Actions]] and link it back here or to the right project.
> - When it arrives → clarify → move to Next Actions / Projects / done, and mark this note done or delete it.
