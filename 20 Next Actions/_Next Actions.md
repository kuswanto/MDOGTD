# ⚡ Next Actions

> [!tip]- How to use
> Physical, visible, 2-minute-capable or longer **single actions** you can do right now. This is where momentum lives.
>
> - Only **one action per note** — the next physical step.
> - Tag each action with a `context` (e.g. `@Computer`, `@Phone`, `@Errands`, `@Home`, `@Office`, `@Anywhere`) so you can batch by where/energy.
> - Link an action to its parent [[30 Projects/_Projects|Project]] via the `project` property so it shows up on the project page too.
> - When done, invert the action: mark `status: done`, set `completed: {{date}}`, and move the note to [[100 Completed/_Completed|Completed]] → `Actions`.
>
> Contexts (GTD): use the `context` property with values like `@Computer`, `@Phone`, `@Home`, `@Errands`, `@Office`, `@Anywhere`, `@Agendas`.
